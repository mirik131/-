Это статичный прототип сайта. Страницы: главная, исследования с формами, витрина анимаций Test, мини админка.
Как запустить

Первый вариант самый простой. Двойной клик по index.html. Все работает.

Второй вариант рекомендуемый, через локальный сервер. Открыть консольку в папке сайта и выполнить python serve.py. Потом открыть в браузере адрес http localhost порт 8000.

Третий вариант любой другой статик сервер. Команда python m http.server 8000.

Чтобы остановить сервер, закрыть окно терминала или убить процесс python.

Папка assets это favicon, og обложка, заглушка QR.

serve.py это локальный сервер с кодировкой utf8. 
На хостинг не заливать.

Заявки с форм

Сохраняются в браузере в localStorage под ключом t1leads. Смотрятся в admin.html в разделе Заявки. Серверной отправки в прототипе нет.

Перенос на WordPress

Тексты из config.js переезжают в ACF поля и кастомайзер.

Тумблеры из admin.html становятся чекбоксами ACF для показа и скрытия блоков.

Формы заменяются на Contact Form 7 или FluentForms.

serve.py и заявки в localStorage не переносятся, их заменяет серверная логика WordPress.
